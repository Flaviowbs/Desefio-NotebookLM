# Desefio-NotebookLM
# Caderno Temático com NotebookLM — Segurança da Informação

## Objetivo do Projeto

Este projeto foi desenvolvido como parte do desafio da DIO com foco na utilização da Inteligência Artificial como ferramenta de aprendizagem ativa.

O tema escolhido foi **Segurança da Informação e Guerra Cibernética**, com o objetivo de:

- Consolidar conceitos fundamentais de cibersegurança;
- Aprender técnicas de curadoria de conteúdo;
- Utilizar IA para resumir conteúdos complexos;
- Criar um material reutilizável para revisões futuras;
- Desenvolver habilidades práticas com engenharia de prompts.

> "Explique os principais pilares da segurança da informação de forma didática."

# Mini Guia de Estudos

## O que é Segurança da Informação?

Conjunto de práticas utilizadas para proteger sistemas, redes e dados contra acessos não autorizados, ataques e falhas.

---

## Princípios Fundamentais

### Confidencialidade
Garantir que apenas pessoas autorizadas tenham acesso às informações.

### Integridade
Assegurar que os dados não sejam alterados indevidamente.

### Disponibilidade
Garantir acesso às informações quando necessário.

---

# Principais Ameaças Cibernéticas

- Phishing
- Malware
- Ransomware
- Engenharia Social
- Ataques DDoS

---

# Guerra Cibernética

A guerra cibernética envolve ataques digitais realizados entre países ou grupos organizados com objetivos estratégicos, políticos ou militares.

---

# Glossário

| Termo | Definição |
|---|---|
| Phishing | Técnica de fraude para roubo de informações |
| Malware | Software malicioso |
| Firewall | Sistema de proteção de rede |
| Ransomware | Malware que sequestra dados |
| VPN | Rede privada virtual |
